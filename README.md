# Berlin Power Forecast
- Author: Mytarev Timur

## This project forecasts power grid load in Berlin based on weather parameters 
## (temperature, humidity, wind speed) and time characteristics.
## The script first demonstrates a simple linear regression model
## (comment section) for baseline performance, and then improves it using an ensemble approach.
